# ⚡ Infinity Electronics Landing Page

A modern, responsive, and professional **electronics landing page website** built using **HTML, CSS, and JavaScript**. The project is designed to showcase electronic products with a clean user interface, smooth scrolling, and responsive layouts.

## 🚀 Features

- Responsive design (Mobile, Tablet, Desktop)
- Modern and minimal UI
- Smooth scrolling navigation
- Hero banner section
- Featured product cards
- Product categories section
- About section
- Contact section
- Hover animations
- Clean and organized code structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Responsive Web Design
